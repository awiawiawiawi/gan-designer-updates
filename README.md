# gan-designer-updates

ROM מותאם אישית ל‑Samsung Galaxy A21s (SM-A217F / SM-A217M), מבוסס על קוד המקור של LineageOS 22.2 (אנדרואיד 15).

השינויים נמצאים בתוך המערכת עצמה, בלי Magisk ובלי רוט.

## מה יש כאן

| נתיב | מה זה |
|---|---|
| `server/gan_server.py` | שרת הניהול ולוח הבקרה, רץ על השרת הביתי |
| `rom/vendor_extra/GanAgent/` | תוכנת הניהול שבנויה בתוך המערכת של המכשיר |
| `rom/frameworks_base/.../GanInstallPolicy.java` | הקוד שבודק כל התקנה מול רשימת האפליקציות המותרות |
| `rom/patches/` | השינוי במנהל החבילות של אנדרואיד שקורא לבדיקה |
| `rom/vendor_extra/gan/allowed_packages.txt` | רשימה התחלתית, בתוקף עד שהמכשיר מקבל הוראות מהשרת |
| `scripts/` | סקריפטים להורדת הקוד, החלת השינויים ובנייה |

## איך הניהול מרחוק עובד

1. בלוח הבקרה קובעים אילו אפליקציות מותר להתקין, שעות נעילה, ונעילה מיידית.
2. השרת חותם על ההוראות במפתח פרטי שנשמר רק אצלו.
3. המכשיר מושך את ההוראות כל רבע שעה בערך ובכל הדלקת מסך, ומדווח לשרת סוללה, גרסה ואפליקציות מותקנות.
4. המכשיר מקבל רק הוראות שחתומות במפתח הנכון. הבדיקה נעשית גם בתוך מנהל החבילות של אנדרואיד, כך שאי אפשר לעקוף אותה משינוי הגדרות.

כל התקנה או עדכון של אפליקציה (מחנות, מקובץ APK או דרך ADB) נבדקים מול הרשימה. אפליקציות שבנויות בתוך המערכת לא מושפעות ממנה.

בזמן נעילה המסך נכבה מיד בכל פעם שמדליקים אותו. **גם שיחות חירום לא זמינות בזמן נעילה.**

## הפעלת השרת

צריך פייתון 3 ואת הספרייה `cryptography`:

```bash
sudo apt-get install -y python3 python3-cryptography
```

פעם אחת, יוצרים מפתחות וסיסמה. בכתובת שמים את הכתובת שבה המכשיר יגיע לשרת:

```bash
./server/gan_server.py init --url http://כתובת-השרת:8750
```

הפקודה מדפיסה את סיסמת לוח הבקרה (פעם אחת בלבד) ויוצרת את הקובץ `server/data/device_config.json`. מעתיקים אותו לפני הבנייה:

```bash
cp server/data/device_config.json rom/vendor_extra/gan/device_config.json
```

מפעילים את השרת:

```bash
./server/gan_server.py run --port 8750
```

לוח הבקרה נפתח בדפדפן בכתובת השרת, עם שם המשתמש `admin` והסיסמה שהודפסה.

- התיקייה `server/data` מכילה את המפתח הפרטי. צריך לגבות אותה: אם היא אובדת, המכשיר לא יקבל הוראות חדשות עד שצורבים מערכת חדשה.
- שינוי כתובת השרת מחייב בנייה וצריבה מחדש.
- השרת מדבר בלי הצפנה. ההוראות עצמן מוגנות בחתימה, אבל סיסמת לוח הבקרה עוברת גלויה. לגישה מחוץ לבית צריך לשים לפניו שרת עם תעודת אבטחה, או רשת פרטית מוצפנת.

## דרישות למחשב הבנייה

- אובונטו 22.04 או 24.04
- 300GB דיסק פנוי
- 16GB זיכרון לפחות (עדיף 32GB)

## בנייה

```bash
git clone https://github.com/awiawiawiawi/gan-designer-updates.git
cd gan-designer-updates

./scripts/1-setup-machine.sh    # פעם אחת: התקנת כלי הבנייה
./scripts/2-sync-source.sh      # הורדת קוד המקור (כמה שעות)
./scripts/4-build.sh            # החלת השינויים ובנייה (כמה שעות)
```

קוד המקור יורד ל‑`~/android/lineage`. אפשר לשנות את המיקום עם המשתנה `ROM_DIR`.

לפני הבנייה מפעילים את השרת פעם אחת ומעתיקים את `device_config.json`, כמו שמוסבר למעלה. בלי הקובץ הזה המערכת נבנית בלי ניהול מרחוק.

אחרי שינוי בקוד מריצים שוב רק את `4-build.sh`. בנייה חוזרת מהירה בהרבה.

## צריבה

בסוף הבנייה נוצרים בתיקייה `~/android/lineage/out/target/product/a21s/`:

- `recovery.img`
- `lineage-22.2-…-UNOFFICIAL-a21s.zip`

לפני הצריבה המכשיר צריך להיות עם קושחת סמסונג של אנדרואיד 12 ועם Bootloader פתוח. הצריבה מוחקת את כל המידע במכשיר.

1. מכבים את המכשיר ונכנסים למצב Download: מחזיקים את שני כפתורי הווליום ומחברים כבל USB למחשב.
2. צורבים את ה‑recovery עם Heimdall:
   ```bash
   heimdall flash --RECOVERY recovery.img --no-reboot
   ```
3. מנתקים את הכבל, מחזיקים Volume Down + Power עד שהמסך נכבה, ומיד עוברים ל‑Volume Up + Power כדי להיכנס ל‑recovery.
4. ב‑recovery בוחרים Factory reset ואז Format data / factory reset.
5. בוחרים Apply update ואז Apply from ADB, ומהמחשב:
   ```bash
   adb sideload lineage-22.2-*-UNOFFICIAL-a21s.zip
   ```
6. בוחרים Reboot system now.

## מצב הבדיקות

- השרת ולוח הבקרה נבדקו בהרצה: כניסה בסיסמה, שמירת הוראות, דחיית קלט לא תקין, קבלת דיווח.
- קוד המכשיר עבר הידור מול ספריות אנדרואיד 15.
- אימות החתימה נבדק מקצה לקצה: הוראות מהשרת מתקבלות, והוראות ששונו נדחות.
- הפאץ' מוחל בלי שגיאות על קוד המקור של `lineage-22.2`.
- בנייה מלאה של המערכת והרצה על מכשיר עדיין לא נעשו.
